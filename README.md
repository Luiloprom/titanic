## Solucion propuesta 
- Para resolver este ejercicio he creado un servicio de emergencias el cual mediante procesos despliega botes. 
- Cada bote se autogestiona solo y simula datos aleatoriamente para luego simular un conteo y comunicar al servicio de emergencia el resultado a traves de su salida estandar imprimiendo por pantalla.
- El servicio de emergencia almacena esos datos y llama a la factoria de generadores de informe que le devuelve un generador adecuado para la extension que se quiera 
> De momento solo esta implementado en Markdown
- Por ultimo el generador de informe se encarga de generar el informe y guardarlo en la carpeta `resources`
